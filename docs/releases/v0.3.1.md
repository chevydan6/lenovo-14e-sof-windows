# Speaker DSP v0.3.1 — adjusted output limit

This release enables the speaker DSP in Windows' live audio path and removes
the preview's extra 6 dB output attenuation. The sample limiter ceiling is
now -1 dBFS instead of -6 dBFS. The limiter and the kernel amplifier watchdog
remain enabled.

The Windows integration fixes include default-mode MFX registration, COM
aggregation, a DLL version resource, integrity-check linking, page-hash
signing and deployment to System32. The installer can verify live processing
and restore the previous effects if verification fails.

The package targets the Lenovo 14e Chromebook Gen 3 / Google Pujjoteen running
Windows 11 x64 with an already working SOF audio driver. It updates speaker
effects only: no kernel driver or firmware is bundled, and existing stereo
or right-only kernel routing is preserved. This build is test-signed and
requires Windows test mode. It does not change boot policy.

## Install

Extract the binary ZIP. For this test build, an administrator must trust the
included public certificate in the machine Root and TrustedPublisher stores:

```powershell
Import-Certificate -FilePath .\dsp-test-signer.cer -CertStoreLocation Cert:\LocalMachine\Root
Import-Certificate -FilePath .\dsp-test-signer.cer -CertStoreLocation Cert:\LocalMachine\TrustedPublisher
.\install.ps1 -VerifyPlayback
```

Run in elevated 64-bit PowerShell. If an earlier version of these effects is
installed, run its `install.ps1 -Rollback` first. Keep the package for recovery;
`install.ps1 -Rollback` restores the previous speaker effects and removes the
managed system DLL. Audio services restart during installation and rollback.

## Verification

Native COM/aggregation, format, limiter/bounds, channel-isolation, silence,
latency and reset tests pass. Live playback of the adjusted build processed
159,360 frames at 48 kHz stereo with zero DSP errors. The integration also
passed desktop-session playback and rollback/reinstallation checks.

The assets include the tested binary package, complete source archive and
SHA-256 checksums. The signing certificate is public; no private signing keys,
firmware or machine-specific debug logs are included.
